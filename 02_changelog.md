## [1.0.0-MVP] — 2026-11-11
### Добавлено
- Оконный интерфейс Y2K Retro OS (Windows 98) с поддержкой drag-and-drop окон, CRT scanline оверлеем и таскбаром.
- Трехосевой процедурный генератор отмазок: "Уровень абсурда", "Степень жалости", "Техническая заумность".
- Холст Canvas 2D для генерации фейковых доказательств:
  - BSoD (Blue Screen of Death Windows 98 / NT).
  - Linux Kernel Panic.
  - Ошибка роутера 502 / 500 Bad Gateway.
  - Терминальный лог фатальной ошибки компилятора.
- Telegram-бот с полноценным инлайн-режимом (`@AlibiGenBot`) и командой генерации картинок `/crash`.
- Тестовый набор Pytest и сервер FastAPI.
