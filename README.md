## 🎯 Features
1. **Nostalgic Y2K Windows 98 Desktop:** Draggable window manager, CRT scanlines toggle, classic bevel 3D buttons, start menu, system clock.
2. **Tri-Axis Procedural Excuse Matrix:**
   - **Уровень абсурда (0–100%):** From minor domestic mishaps to cosmic ray bitflips and alien microcode injections.
   - **Степень жалости (0–100%):** Emotional leverage, flooded apartments, dental emergencies, sick cats.
   - **Техническая заумность (0–100%):** BGP route poisoning, Kubernetes OOMKilled, PostgreSQL deadlocks, kernel mutex starvation.
   - **Target Persona:** Client, Team Lead, Boss, Spouse, Professor.
3. **Fake Technical Crash Evidence Generator:**
   - Instant dynamic Canvas 2D and Pillow renderer.
   - Realistic **Blue Screen of Death (BSoD)** with authentic hex memory dump addresses.
   - **Linux Kernel Panic** with register dump.
   - **HTTP 502 / 500 Bad Gateway** with user's fake IP and Ray ID.
   - **Compiler Fatal Error Dump** (C++, Rust, TypeScript).
   - "Download Screenshot PNG" & "Copy Error Trace".
4. **Telegram Companion Bot with Inline Mode:**
   - Type `@AlibiGenBot [keyword]` anywhere in Telegram to send instant excuses.
   - `/crash [bsod|panic|gateway500|compiler]` generates and sends photo evidence.

## 🚀 Quick Start

### 1. Web & API Server
```bash
cd Case07_AlibiGenPro
pip install -r requirements.txt
python api/server.py
```
Open [http://localhost:8007](http://localhost:8007) in your browser.

### 2. Telegram Bot
```bash
python bot/bot.py
```

### 3. Run Tests
```bash
pytest tests/test_alibigen.py -v
```
